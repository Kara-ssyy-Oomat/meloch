Нет изменений
⚠️ Перерасчёт не меняет заказы и историю продаж. Новая себестоимость хранится отдельно, и в «Отчёте по прибыли» можно переключаться между прибылью на момент продажи и прибылью после перерасчёта. Повторный перерасчёт того же периода заменяет прошлый результат, а не прибавляет разницу ещё раз.
Параметры перерасчёта
«Текущие приходные цены» — для каждого проданного товара берётся его приходная цена из каталога сейчас. Если выбрать конкретное изменение из истории — пересчитаются только товары из этого изменения.
